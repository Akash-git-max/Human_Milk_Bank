Human Milk Bank System
The Human Milk Bank System is designed to streamline the donation, processing, and distribution of donor human milk to neonatal intensive care units and infants in need.
The system automates donor registration, milk collection, pasteurization, and recipient distribution, ensuring efficiency and quality control.

Features
1. Donor & Recipient Management: Secure registration, tracking, and data management.
2. Milk Processing & Storage: Ensures safety with pasteurization and culture testing.
3. Inventory & Distribution Tracking: Maintains real-time records of available milk and dispensed units.
4. User Authentication & Security: Role-based access control for admin, healthcare professionals, and donors.
5. Reports & Analytics: Generates data insights on milk donations and usage.

Tech Stack
Frontend: HTML, CSS, JavaScript, Bootstrap
Backend: Java with Hibernate, MySQL
Tools: Eclipse IDE, Apache Tomcat
